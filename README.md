## 费率算账：0.02 个百分点值多少钱

把百分比换成美元，差距才看得见。

**永续合约吃单**：1 万美元市价单，OKX 收 5.00 美元，Bybit 收 5.50 美元。单笔差 0.5 美元，每月 100 笔就是 50 美元。挂单方两家都是 0.02%，这一项没差别。

**现货限价单**：1000 美元挂单成交，OKX 收 0.80 美元，Bybit 收 1.00 美元，差 0.2 美元。市价单两家都是 1.00 美元，打平。

有三件事会把这笔账搅乱，下单前必须知道。

**资金费用每 8 小时结算一次。** 永续合约多空双方互相支付，行情拥挤时单次资金费率可能超过手续费本身。做趋势单的人盯着点差，做长线持仓的人更该看资金费率曲线。
